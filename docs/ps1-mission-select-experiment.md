# French PS1 mission-selection experiment

On November 6, 2026, the French disc `SCES-01911` was launched in RetroArch 1.22.2 with PCSX ReARMed r26 `7b0e8f8` and HLE BIOS, using disposable configuration and save states with SRAM loading and saving disabled. The disc BIN SHA-256 was `c0f54d8110eb87b802cb6cadb304251fa5910eafa193a5de16cd2c2651911e72`. Georgia Street was started, and a state was saved while the French options menu highlighted **SÉLECTIONNER LA MISSION**.

The [PSX Data Center entry for SCES-01911](https://psxdatacenter.com/games/SCES-01911.html) and [GameFAQs cheat listing](https://gamefaqs.gamespot.com/ps/198876-syphon-filter/cheats) describe holding L1, L2, R1, Square, Circle and Cross at this menu. An isolated controller configuration mapped these six virtual buttons to one keyboard key. Pressing it opened the mission list, but the only displayed entry was Georgia Street. A second isolated configuration mapped five buttons to one key and Cross to another; holding the first and pressing Cross also displayed only Georgia Street. An earlier test using `h` was confounded by RetroArch's reset hotkey and is not evidence about the cheat.

These attempts do not establish whether the key mappings produced the intended simultaneous PS1 inputs or whether the published code applies under these conditions. They do **not** demonstrate that the code is invalid. No other mission was accessed or observed, and no mission progression or canonical initial state can be inferred. The [coverage table](ps1-runtime-mission-coverage.csv) therefore remains unchanged. Future work should independently verify the virtual controller inputs, test a physical controller or debugger, and document any cheat-altered starting state.
