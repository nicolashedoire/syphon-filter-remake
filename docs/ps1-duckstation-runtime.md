# French PS1 runtime: DuckStation isolated session

On November 6, 2026, an isolated portable installation of DuckStation 0.1-12442 ran the French `SCES-01911` disc on macOS 15.1.1 ARM64. The official macOS release archive SHA-256 was `b9f6f0e747ee2617988de33e1fafdd17d02e918d042fed691355aed9a86c11cd`, matching the publisher's listed digest. The locally available OpenBIOS from PCSX-Redux had SHA-256 `f325a4e973f5023e22484c2cb408809717ece63cf39c9192f681b76e94148bc8`; DuckStation [recognizes OpenBIOS](https://github.com/stenzek/duckstation/blob/master/src/core/bios.cpp), but that does not establish full compatibility with this game or real hardware.

The emulator's portable configuration, its newly created memory card and its save states are confined to the investigation workspace. After the title sequence and French briefing, a new game reached the beginning of Georgia Street. In this run, keyboard Up moved Gabe towards the police car. The emulator saved a local state to slot 1 using F2; after this movement, F1 restored Gabe visibly to the earlier position without restarting the emulator. Start opened the French in-game map and objective menu, and the emulator was left open there. This is one successful save/load trial, not proof of long-term stability, accuracy or successful save-state portability between emulators.

In the isolated default keyboard mapping, Cross is K, Triangle is I, Circle is L, Square is J, Start is Return, directional movement uses arrow keys, and holding Tab speeds up emulation. F2 saves the selected state, F1 loads it, and F3/F4 switch slots. These bindings describe this local configuration only; they do not change the browser remake's L2 target lock, R2 fire or following camera. The French disc and save-state files are not included in this repository.

The run did not establish complete enemy behavior, roll timing, other missions' objectives or cinematics. Continue controlled observations using saved states in this still-running session; record inputs, setup and uncertainties, and verify state changes against the original executable before making gameplay claims.
