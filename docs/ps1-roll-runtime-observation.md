# French PS1 roll: isolated runtime observation

On November 6, 2026, the French SCES-01911 disc (BIN SHA-256 `c0f54d8110eb87b802cb6cadb304251fa5910eafa193a5de16cd2c2651911e72`) was launched in RetroArch 1.22.2, PCSX ReARMed r26 `7b0e8f8`, HLE BIOS. The process used a separate research configuration and directories, with SRAM loading and saving disabled. HLE is not proof of identical behavior on original hardware. No remake gameplay was modified.

Starting a new game, continuing the French briefing and skipping the opening sequence reached Georgia Street. A manual press of keyboard `x` (mapped by this isolated RetroArch configuration to the PS1 Circle action) was followed by the observed player character turning over on the ground. The emulator was paused and successive `k` frame-advance inputs showed changed poses, including a head-down posture and later recovery. Screenshots were saved locally. Two armed characters and a danger indicator were visible in the scene; their specific state transitions and cause of any damage were not isolated.

This establishes that a roll-like movement occurred after the input in this particular run. It does not identify the active HAN clip, prove the precise moment of transition, measure duration or displacement, establish invulnerability, or establish forward/side-roll behavior across input combinations. The screenshot immediately after the input was not a measured animation start; frame-advance taps were not cross-checked against a recorded frame counter. Therefore the number of taps cannot be used as an original roll duration. No memory trace was captured.

The in-game objectives menu in this run again displayed the Kravitch/transmitter objective and the Rhoemer objective. No other mission was entered during this session: [mission runtime coverage](ps1-runtime-mission-coverage.csv) lists the other 19 as not yet verified. The existing game-inventory and web behavior gap assessments remain unchanged.

To repeat, launch the local French disc with an isolated RetroArch configuration and PCSX ReARMed HLE, choose Nouvelle partie, continue with Cross, skip the opening sequence with Start, exit the in-game map with Triangle, press Circle and pause. On this setup `z` = Cross, `s` = Triangle, `x` = Circle, `Enter` = Start, `p` = RetroArch pause and `k` = frame advance. Record the build/core/configuration, disc hash and actions; use only disposable emulator state. The current follow camera and L2 lock / R2 fire in the remake remain the user's chosen exceptions.
